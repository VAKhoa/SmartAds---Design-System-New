# SmartAds Design System (SDS)

Đây là file `AGENTS.md` duy nhất trong dự án: điểm vào theo quy ước để Codex tự đọc, không phải tên một agent cần gọi. Khi làm việc trong dự án, đọc `SDS-docs/content/rules/SDS-rules.md` để lấy quy tắc chi tiết cho nội dung, Figma, token và website. Xem `SDS-docs/content/guides/workspace-guide.md` để chọn quy trình và lệnh kiểm tra theo loại task.

Nguồn thiết kế SmartAds là Figma được chỉ định trong `SDS-docs/ds.config.json`. Mọi file sinh tự động phải được sửa từ đầu vào hoặc script sinh, không sửa trực tiếp output.
