# SmartAds Design System (SDS)

Đây là file `AGENTS.md` duy nhất trong dự án: điểm vào theo quy ước để Codex tự đọc, không phải tên một agent cần gọi. Khi làm việc trong dự án, đọc `SDS-docs/content/rules/SDS-rules.md` để lấy quy tắc chi tiết cho nội dung, Figma, token và website. Xem `SDS-docs/content/guides/workspace-guide.md` để chọn quy trình và lệnh kiểm tra theo loại task.

Nguồn thiết kế SmartAds là Figma được chỉ định trong `SDS-docs/ds.config.json`. Mọi file sinh tự động phải được sửa từ đầu vào hoặc script sinh, không sửa trực tiếp output.

**Công nghệ component:** code component thực tế triển khai từ Figma, ví dụ để Dev copy và code trong handoff phải dùng **HTML/CSS/JavaScript thuần**, chạy độc lập với framework. Đọc `SDS-docs/content/rules/component-code-rules.md` trước khi thực hiện. Website tài liệu vẫn giữ Next.js/React và cách trình bày hiện tại; React/JSX của shell, viewer hay công cụ tài liệu không phải code component bàn giao cho sản phẩm. Không chuyển đổi website sang stack khác vì quy tắc này.

Trước khi đọc file Figma SmartAds, ưu tiên plugin cục bộ **`figma-local@figma-local-workspace`** và gọi `whoami` để xác minh tài khoản **`info@smartads.tech`**. Dùng các công cụ đọc metadata, design context, screenshot hoặc export của plugin để lấy dữ liệu mà không điều khiển giao diện máy. Nếu plugin chưa cấp công cụ, chưa xác thực đúng email hoặc thiếu quyền đọc/Inspect, ghi rõ giới hạn và không kết luận từ một phiên khác. Không tự chuyển sang plugin Figma marketplace, app desktop hoặc Chrome khi người dùng chưa yêu cầu cách đó. URL có `?m=dev` chỉ mô tả chế độ, không xác nhận tài khoản hay quyền Dev Mode. Nếu sau này được giao dùng app desktop, chuyển sang Dev Mode ngay khi mở đúng file và xác minh panel Inspect; không dùng phiên `anhkhoavan888@gmail.com` hoặc `smartads@fpt.com` để kết luận về SmartAds.

Chỉ truy cập **đúng file Figma được người dùng chỉ định cho task hiện tại**: kiểm tra file key trong URL trước khi gọi plugin và không duyệt Recents, file khác hoặc thư viện liên kết để lấy thêm dữ liệu khi chưa được giao. Nếu chưa xác định được file, hỏi rõ thay vì tự chọn. Làm việc ở chế độ chỉ đọc; khi truy cập bằng app theo yêu cầu riêng, mặc định chuyển sang **Dev Mode**. Không tạo, sửa, đổi tên, di chuyển, xóa, publish hoặc thay đổi bất kỳ nội dung/cài đặt nào trong Figma nếu người dùng chưa cho phép rõ ràng hành động đó trên đúng file. Quyền chỉnh sửa website hoặc tài liệu SDS không đồng nghĩa quyền chỉnh sửa Figma.
