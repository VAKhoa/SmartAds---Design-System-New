# SmartAds Design System (SDS)

Hai tài liệu bắt đầu nằm trong [`content/guides/`](content/guides/):

1. [SmartAds và SDS là gì?](content/guides/about-smartads.md) — sản phẩm SmartAds, mục tiêu của SDS và người sử dụng.
2. [Hướng dẫn thư mục và vận hành](content/guides/workspace-guide.md) — chọn đúng skill theo task, prompt mẫu, kiểm tra trước khi build và cách chạy website.

Nếu mới tiếp nhận dự án, đọc theo thứ tự trên. Dữ liệu thiết kế gốc nằm trong [Figma SmartAds Design System](https://www.figma.com/design/cRZ5kIi4kD6j9lh1dbh5mh/SmartAds---Design-System); `variable-figma-export/` là bản chụp trong thư mục này.

Website nằm trong [`website/`](website/). Xem [cách chạy và sửa website](website/README.md); trước khi tạo bài cho một mục sidebar, xem [bảng tên file Markdown](content/guides/content-guide.md). Từ thư mục website chạy `npm ci` rồi `npm run dev` để xem giao diện cục bộ.

Xem [bản đồ toàn bộ tài liệu Markdown](content/README.md) để biết file quy tắc, hướng dẫn và bài website nằm ở đâu.
