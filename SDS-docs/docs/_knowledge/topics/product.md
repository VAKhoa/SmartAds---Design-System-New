# Sản phẩm & người dùng

> Tổng hợp 2026-11-15 · Nguồn: `SDS-docs/content/guides/about-smartads.md` (updated 2026-11-03, status in-review) · Tin cậy: High (phần SmartAds lấy từ website công khai smartads.tech; phần mục tiêu SDS chờ chủ dự án duyệt).

- **SmartAds** (smartads.tech): nền tảng AdTech self-serve ads manager + analytics/reporting; quảng cáo native, nhắm theo ngữ cảnh/hành vi/retargeting (là khả năng nền tảng, không phải quy tắc SDS).
- **Người dùng sản phẩm:** Advertiser (tạo chiến dịch, ngân sách, theo dõi kết quả), Publisher (quản lý vị trí/định dạng, inventory), Reader (người đọc, không quản trị).
- **SDS** = nguồn tham chiếu thiết kế chung; dự kiến 4 lớp: Foundations · Design tokens · Components · Tài liệu cho người và máy. Đây là **định hướng**, chưa phải tính năng hoàn thành.
- **Người dùng SDS** (khác người dùng sản phẩm): Product/Design lead, Designer, Developer, QA, AI agent.
- **Trạng thái:** chưa có gói CSS token phát hành hoặc thư viện component code cho sản phẩm (`SDS-rules.md` dòng 11).
- **Nghiệp vụ AdTech trong thiết kế** (đã/chưa có): xem `SDS-CONTEXT.md` §9 — KPI card, bảng dữ liệu, lifecycle, wizard, budget/bid VND, date range; thiếu: delta, status lifecycle đủ, density, targeting, compare period.
- Website mẫu VDS (`Prompt Docs VNE (DON'T TOUCH)`, ngoài repo) chỉ là mẫu cấu trúc, không phải thương hiệu SmartAds.
- Lệch: bài về-SmartAds còn nói website chỉ có "bài Colors" → X5 ở open-questions.
