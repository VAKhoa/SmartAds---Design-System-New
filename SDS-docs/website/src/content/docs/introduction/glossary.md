## Hệ thống và thành phần

| Thuật ngữ | Ý nghĩa |
| --- | --- |
| SDS | SmartAds Design System, hệ thống thiết kế của SmartAds. |
| Design system | Các quyết định, thành phần và hướng dẫn dùng chung để xây dựng giao diện. |
| Foundation | Nền tảng thiết kế như màu sắc, typography, spacing và radius. |
| Component | Thành phần giao diện có thể tái sử dụng với mục đích và hành vi xác định. |
| Variant | Biến thể của một component, chẳng hạn kích thước hoặc mức nhấn. |
| State | Trạng thái của giao diện, chẳng hạn đang chọn, đang xử lý hoặc không khả dụng. |

## Dữ liệu thiết kế

| Thuật ngữ | Ý nghĩa |
| --- | --- |
| Design token | Giá trị thiết kế được đặt tên để tham chiếu và dùng lại. |
| Variable | Định nghĩa giá trị trong Figma, có thể có giá trị theo mode hoặc tham chiếu variable khác. |
| Collection | Nhóm variables trong Figma, có hệ thống mode riêng. |
| Mode | Một bộ giá trị của collection, ví dụ Light hoặc Dark. |
| Alias | Tham chiếu từ một variable đến variable khác. |
| Semantic token | Token diễn đạt vai trò sử dụng, chẳng hạn nền, chữ hoặc viền. |
| Style | Tập thuộc tính thiết kế dùng chung, chẳng hạn text style hoặc effect style. |
| Snapshot | Bản chụp dữ liệu tại một thời điểm; cần đồng bộ lại để nhận thay đổi mới. |

## Triển khai và vận hành

| Thuật ngữ | Ý nghĩa |
| --- | --- |
| CSS custom property | Biến CSS, thường có tên bắt đầu bằng `--`; SDS dùng tiền tố `--sa-`. |
| Responsive | Cách giao diện điều chỉnh theo không gian hiển thị. |
| Accessibility | Khả năng sử dụng sản phẩm của những người có nhu cầu và cách tương tác khác nhau. |
| AI agent | Trợ lý thực hiện công việc dựa trên yêu cầu, ngữ cảnh và công cụ được cung cấp. |
| Skill | Hướng dẫn tái sử dụng cho một loại công việc của agent. |
| Review | Đối chiếu và đánh giá kết quả trước khi duyệt áp dụng. |

Nếu chưa biết nên đọc gì trước, quay lại [Getting Started](/introduction/getting-started/).
